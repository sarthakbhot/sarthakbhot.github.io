Project

Folio

A personal expense tracker and budget copilot. It watches the month with you: what already landed, what is still coming, and what the budget should do about it.

Next.js Cloudflare Workers vinext Plaid Web push

Screenshots use fake demo data.

I built Folio because a list of transactions is not a budget. Card activity syncs through Plaid and can remember a merchant, so the next charge lands in the same category. Recurring charges are pulled out on their own. A payoff planner lines balances up so the expensive debt goes first. Net worth rolls savings and investments into one view. Budget copilot asks a few questions about pay, a savings goal, and priorities, starts from what the accounts already show, and writes a budget that updates as new transactions land.

How it's built

Folio is a Next.js app, deployed to Cloudflare Workers with vinext. Plaid links the accounts. The interface is dark, and it is laid out for a phone as well as a wide window. Alerts use web push.
