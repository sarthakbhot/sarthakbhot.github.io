Project

Folio

A personal expense tracker and budget copilot. It watches the month with you: what already landed, what is still coming, and what the budget should do about it.

Next.js Cloudflare Workers vinext Plaid Web push

Screenshots use fake demo data.

Overview.

The main screen. What went out this month, which cards moved, and what shifted.

Income.

Money in, set next to spending, and a split for where the next deposit goes.

Pay.

Log shifts and estimate a paycheque, including tax, CPP, and EI.

Budgets.

A limit and a pace for each category, plus room still left this month.

Trends.

A week-by-week heatmap of where spending landed.

Cards.

A nudge when a card has gone quiet, so it is not closed for inactivity.

Alerts.

Notices for new charges, unusual amounts, duplicates, and price changes. On iPhone they can arrive as web push from a home-screen install.

Case study

Problem
A list of transactions is not a budget. I wanted one place that could pull spending in, sort it, notice repeating charges, and show whether the month was still on track.
What I built
Card sync through Plaid, categories that can remember a merchant, recurring-charge detection, an income view, an avalanche payoff planner, adaptive budgets with alerts and web push, a pay and shift estimator, a net worth view, and a budget copilot that writes a plan from what the accounts already show.
Stack
Next.js, deployed to Cloudflare Workers with vinext. Plaid for linking accounts. Web push for alerts.
Outcome
Folio is built and shown on this page with fake demo data. It is not linked as a public app.

How it's built

Folio is a Next.js app, deployed to Cloudflare Workers with vinext. Plaid links the accounts. The interface is dark, and it is laid out for a phone as well as a wide window. Alerts use web push.
