How I built Folio

An expense tracker and budget copilot. This note is the product and the stack, nothing else.

A list of transactions is not a budget. I wanted one place that could pull spending in, sort it, notice the charges that repeat, and tell me whether the month was still on track.

What it does

  • Card transactions sync through Plaid. A category can remember a merchant, so the next charge lands in the same place.
  • Recurring charges are pulled out on their own, including what is still committed for the month.
  • An income view sits next to spending.
  • Budgets show a limit and a pace for each category, and can roll unused room forward. Alerts and web push, including from a home-screen install on iPhone, flag what needs a look.
  • A payoff planner lines balances up so the expensive debt goes first.
  • Logging a shift produces a paycheque estimate, including tax, CPP, and EI. The figures in the screenshots are examples.
  • Savings and investment accounts roll into a net worth view.
  • Budget copilot asks about pay, a savings goal, and priorities, starts from what the accounts already show, and writes a budget that updates as new transactions land.

Stack

Folio is a Next.js app, deployed to Cloudflare Workers with vinext. Plaid links the accounts. Alerts use web push. The interface is dark, and it is laid out for a phone as well as a wide window.

The screenshots on the project page use fake demo data. There is no public app link on this site.
